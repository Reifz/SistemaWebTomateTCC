# Rastreador de problemas local

Problemas e documentos de produto deste repositório ficam em arquivos Markdown dentro de `.scratch/`.

## Convenções

- Uma funcionalidade por diretório: `.scratch/<nome-da-funcionalidade>/`.
- O documento de produto fica em `.scratch/<nome-da-funcionalidade>/PRD.md`.
- Os problemas ficam em `.scratch/<nome-da-funcionalidade>/issues/<NN>-<nome>.md`.
- O estado é registrado em uma linha `Status:` no início do arquivo.
- Comentários e histórico são adicionados ao final, sob o título `## Comentários`.
