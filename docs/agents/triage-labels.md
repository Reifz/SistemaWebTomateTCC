# Rótulos de triagem

| Papel canônico | Rótulo local | Significado |
| --- | --- | --- |
| `needs-triage` | `precisa-triagem` | Precisa ser avaliado |
| `needs-info` | `precisa-informacoes` | Aguarda mais informações |
| `ready-for-agent` | `pronto-para-agente` | Especificado e pronto para um agente |
| `ready-for-human` | `pronto-para-humano` | Requer implementação humana |
| `wontfix` | `nao-sera-feito` | Não será implementado |
